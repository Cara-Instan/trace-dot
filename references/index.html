Two directions, same shell.

Pinch is a desktop PDF utility built on Electrobun (Bun + native WebView). v0.1 ships merge, split, history, and settings. This is a side-by-side comparison of two design directions for the same five surfaces — pick a direction and click any screen to walk through it.

Direction 01 · shadcn-baseline

Shadcn minimal

Calm baseline. White surface, hairline borders, generous whitespace, single black accent. Reads as a confident, modern product shell — the kind a team would ship without question.

Data utility

Denser rhythm. Mono metadata, table-like rows, dark title bar, status pills with semantic color. Reads as a tool for users who run the same operations dozens of times a day.

Roadmap
